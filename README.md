# 🇺🇿 Uzbekistan Open Data

## Zaprafkalar (Gas Stations)
O'zbekiston bo'ylab **1,511 ta** zaprafka ma'lumotlari.

### Ma'lumot manbasi
- OpenStreetMap (ODbL litsenziyasi)
- Hojat App (compassx.uz) tomonidan to'plangan

### Fayllar
| Fayl | Tavsif |
|---|---|
| `uzbekistan_gas_stations.json` | 1,511 ta zaprafka (nom, lat, lon) |

### Litsenziya
ODbL — OpenStreetMap shartlari asosida bepul foydalanish mumkin.

### Muallif
[CompassX](https://github.com/ahrorxoja)
